### 🚀 Genel Bakış (Overview)

Bu proje, bir **Bilgisayar Mühendisi** olarak projelerimi, teknik yetkinliklerimi ve deneyimlerimi sergilemek amacıyla geliştirdiğim kişisel web sitemin kaynak kodlarını içermektedir. Site, modern web teknolojileri kullanılarak tamamen duyarlı (responsive) bir yapıda tasarlanmıştır.

### 🛠️ Teknolojiler (Tech Stack)

* **Frontend:** ![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB)
* **Styling:** ![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=flat-square&logo=tailwind-css&logoColor=white) ![Material UI](https://img.shields.io/badge/Material--UI-0081CB?style=flat-square&logo=mui&logoColor=white)
* **State Management:** ![Redux](https://img.shields.io/badge/Redux_Toolkit-764ABC?style=flat-square&logo=redux&logoColor=white)
* **Deployment:** Vercel / Netlify / GitHub Pages

### ✨ Özellikler (Features)

* 📱 **Tam Duyarlı Tasarım:** Mobil, tablet ve masaüstü cihazlar için optimize edilmiş arayüz.
* 📂 **Dinamik Proje Kartları:** Geliştirdiğim projelerin (Certifi, NotlarSende vb.) detaylı gösterimi.
* 📊 **Staj Deneyimi:** LotusAI bünyesinde tamamladığım Veri Bilimi ve ML stajının detayları.
* 📧 **İletişim Formu:** Freelance iş teklifleri ve profesyonel bağlantılar için entegre iletişim bölümü.
